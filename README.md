# Rodood — Service Requests prototype

Interactive prototype of service requests in Rodood, a feature every business on Rodood can use: each business adds its own services, steps and prices; clients request them in the Rodood client app or on WhatsApp. Includes sample businesses (government clearance, travel, real estate) and an empty new business.

Live: https://aaldairi.github.io/rodood-service-requests/

All names, prices and documents are sample data.
